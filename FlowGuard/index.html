📖 FlowGuard AI – How It Works

1. User Input: Enter business rules in plain English (e.g. "If order > ₹50,000, get manager approval and create purchase order.").
2. AI Understands: The AI parser extracts triggers, threshold operators, roles, conditions, and actions.
3. Intermediate Representation (JSON AST): Compiles English into a structured machine-readable JSON AST.
4. Workflow Graph Creation: Instantly generates an interactive, draggable DAG diagram color-coded by step type.
5. 5-Pillar Verification Engine: Checks for Circular Loops (5.1), Unreachable Steps (5.2), Ambiguity (5.3), RBAC Permissions (5.4), and Enterprise Policies (5.5).
6. Is Workflow Valid?: If safe, unlocks the Live Execution Simulator. If issues are detected, AI generates a 1-Click Auto-Fix to repair the rule!
